Dit is een Repro van de HA omgeving van Rients
Ik heb deze gemaakt om de wijzigingen voor mijn omgeving goed bij te houden.
Ik heb deze volledig aangepast nadat ik de Marstek thuis accu aangeschaft heb.

Ik heb dit in verschillende mappen onderverdeeld.
- O Dashboard, bevat de verschillende dashboards die ik op dit moment gebruik.
    - overzicht-dashboard is de hoofd dashboard
    - marstek-dashboard bevat een dashboard om alle details van de thuisaccu uit te lezen, dit alles is gebaseerd op het werk van Fonske
    - expiriment, heb ik ergens van internet gehaald als inspriratei

- 1 ESPHOME bevat de yaml bestanden voor het maken van ESP home devices.

    De image bestanden kunnen gegenereerd worden door: https://esphomeonlinecompiler.com/
    De bestanden worden geprogrammeerd door https://web.esphome.io/

    Ik heb de repro van DerekSeaman gebruikt om de ATOM te programeren voor het identificeren van de IRK om de bluetooth precence mogelijk te maken. https://github.com/DerekSeaman/irk-capture 

- 2 Home Assistant Core, bevat bijgewerkte core bestanden
- 3 Node-Red bevat exports van mijn eigen Node-Red automatiseringen.
- 4 packages bevat de bestanden die in de folder packages staan in HA.
- 5 Bewaarde automatiseringen
